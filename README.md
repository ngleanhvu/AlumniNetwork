# AlumniNetwork

# Sử dụng API của Zoom, Google Meet hoặc các phần mềm video call để tham gia sự kiện online
# Sử dụng RabbitMQ để gửi tin nhắn thông báo thư mời bất đồng bộ
# Xây dựng chatbot hỗ trợ sinh viên tích hợp với AI (Nếu được)
# Sử dụng Firebase để xây dựng ứng dụng chat giữa các cự sinh viên
# Kiểm tra đã đổi mật khẩu đối với giảng viên (chạy background)
# Sử dụng Redis để cache hoặc làm token blacklist
